# 教室クイズ

授業で使う、参加型の4択・〇×クイズです。先生がプロジェクターに問題を映し、生徒は自分のスマホやタブレットから答えます。答えはその場で集計され、正解発表では正解率・答えの分かれ方・解説を全員に見せられます。

## 使い方

### 先生

1. アプリを開き、「先生はこちら」→「新しいクイズ」で問題を作ります。
   - 4択と〇×を1つのクイズに混ぜられます。
   - 正解の選択肢と解説を入れます。図や写真を付けることもでき、先生の画面にだけ表示されます。
   - クイズごとに次の設定を選びます。
     - 参加のしかた：ニックネームのみ／クラス・出席番号も入力（成績用）
     - 制限時間
     - ランキングを表示するかどうか
2. 作ったクイズは、その端末のブラウザに保存されます。別の端末で使うときは「書き出す」でファイルにし、使う端末で「ファイルから読み込む」を押します。
3. 「授業で使う」を押すと、参加コードとQRコードが出ます。これをプロジェクターに映します。
4. 生徒がそろったら「1問目を出す」を押します。そのあとは「締め切る」→「正解発表」→「次の問題へ」の順に進めます。
   - 全員が答えると「全員回答しました」と表示されます。締め切るかどうかは先生が決めます。
   - 制限時間がある問題は、時間が来ると自動で締め切られます。
5. 最後の問題が終わったら、次の順に操作します。
   1. 「CSVを保存」で、生徒ごとの選んだ答え・正誤・正解率をExcelで開ける形で保存します。
   2. 「クラウドから削除して終わる」で、生徒のデータを消します。消し忘れたデータは、24時間後に先生がアプリを開いたとき自動で消えます。

#### 参加者の管理（画面下の「参加者」から）

- **名前を変えてもらう**：ふさわしくないニックネームの生徒に、名前の変更をお願いします。それまでの回答は残ります。
- **退出**：その生徒はそれ以上答えられなくなります。それまでの回答は、退出の印を付けてCSVに残ります。
- **再参加を許可**（成績用）：同じクラス・出席番号で参加し直した人が「許可待ち」として出ます。本人だと確かめてから許可してください。許可すると、前の端末の回答を引き継ぎます。

### 生徒

QRコードを読み取るか、アプリを開いて参加コードを入れ、ニックネームを入力します。成績用のクイズでは、クラスと出席番号も入力します。答えは、締め切りまでなら変えられます。

## 学校のネットワークで使うとき

学校の端末やWi-FiでWebフィルタがかかっている場合は、次の通信先を許可してもらってください。

| 通信先 | 用途 |
|---|---|
| `akito-hashi.github.io` | アプリ本体（公開先） |
| `www.gstatic.com` | Firebase の部品の読み込み |
| `firestore.googleapis.com` | 回答や集計のやり取り |
| `identitytoolkit.googleapis.com`、`securetoken.googleapis.com` | 先生の端末の匿名ログイン |

フィルタが常時接続の通信を遮る環境では、自動で別の通信方式（long polling）に切り替えます。

## 開発

素のHTML/JSで作っています。ビルドの手順はありません。データの保存先は Firebase（プロジェクト `educationquiz-1ad5d`、無料のSparkプラン）です。

- 生徒はログインしません。先生だけ匿名ログインを使います。
- 正解は先生の端末だけが持ち、正解発表のときに初めてクラウドへ送ります。
- `firestore.rules` を変えたときは、Firebase コンソールの Firestore Database →「ルール」に貼り付けて公開してください。

```sh
npm install
npm test              # 集計・CSV などの計算
npm run test:firebase # 本物の Firebase に対するルールと同期のテスト
npm run test:ui       # Mac の Chrome で画面を動かすテスト（Firebase も使う）
node tools/make-icons.mjs  # icons/icon.svg からアプリのアイコン（PNG）を作る
```

ファイルを追加したり名前を変えたりしたときは、`sw.js` の `FILES` を直して `VERSION` を上げてください。

QRコードの生成には [qrcode-generator](https://github.com/kazuhikoarase/qrcode-generator)（MIT License, Copyright (c) 2009 Kazuhiko Arase）を `vendor/qrcode.js` として同梱しています。
